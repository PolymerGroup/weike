05 / METHOD

A record is only useful if its gaps are visible.

The register is built around what can be checked. Public identity data, pack-level pricing and lot-file expectations are kept separate from claims that require a specific batch.

01

Identity before price

CAS, formula and molecular weight are shown where a reliable public record exists. When the source list does not establish identity, the record says so rather than filling the gap.

02

Pack before unit price

Every schedule is listed as a pack. The per-vial figure is derived only where the vial count is known. A headline price without a format is not a comparable number.

03

Lot file before dispatch

A useful lot file connects the analytical result to the batch in the box. We ask buyers to read it. We do not treat a website badge as a certificate.

04

Destination before promise

Freight, import documentation and availability are reviewed for the destination. The quotation states what is included, what is not, and which document set applies.

06 / BUYER QUESTIONS

Questions before a specification.

Short answers on scope, pricing, documentation and use restrictions.

Is this a shop or a register?

It is a reference and sourcing interface, not a consumer checkout. Each row is a material record: identity status, pack schedules, indicative list price and the lot-file questions a laboratory buyer should ask before ordering. A formal quotation and the lot-specific documents follow separately.

What is a 'lot file' on this site?

We use the term for the document set that should travel with a specific batch — typically a lot-specific certificate of analysis plus any safety or handling documents available for that material. Request the file for the lot you will receive and compare it with the order. A generic certificate is not a substitute.

How should I read the price on a record?

Prices are indicative USD list prices per catalog pack, not quotations. The pack format is shown alongside the price, because a 2 mg pack and a 20 mg pack are not comparable units. Freight, duties, taxes and bank charges are excluded until a destination-specific quotation is issued.

Can I compare different research families?

Yes. The comparator places up to four records on one readout, including identity, target, structure, evidence, formats and starting price. It is a reference comparison, not an equivalence claim; different receptor profiles or molecular formats should not be treated as interchangeable because the prices look similar.

Are these products for human or veterinary use?

No. Every material in this register is supplied for laboratory research use only. It is not for human or veterinary use, diagnosis, treatment, compounding, cosmetic application or food use. The site does not provide medical advice or dosing instructions.
